Codemoji · Discord collection bot

Privacy policy (setup phase)

Last updated: October 12, 2026

Collection is not active. The bot has been installed in its operator's test server but the collector is not running. This page separates the intended collection behavior from the currently completed setup. Deletion controls, encrypted collection storage and live scope checks must be finalized before collection begins.

Purpose and scope

Codemoji is a local Windows companion for expressive input in the Codex desktop app. Its optional Discord bot is intended to collect custom emoji, stickers and GIF references deliberately posted by an approved account in explicitly selected channels of an approved collection server. It is not intended to monitor direct messages, other servers or general conversations.

What the bot will receive and retain

Discord delivers message events and permitted history through its official bot API. Those events can include surrounding text and other metadata. The collector must validate server, channel and author scope before expression processing; raw message payloads and surrounding conversation text must not be retained or logged.

The intended collection records include:

  • Server, channel, source-message and expression identifiers needed for collection membership, updates and duplicate prevention.
  • Emoji or sticker names, animation or format information, and relevant media or provider-page references.
  • Collection labels, separately chosen favorites and Codemoji usage records, where those features are implemented.

Provider-page references are not necessarily downloadable media files. Media retrieval, previews and format handling are not implemented by the initial classifier. Collection access does not grant rights to reproduce or redistribute someone else's content.

Storage and credentials

The bot credential is stored outside the project source in a device-local file encrypted with Windows DPAPI for the current Windows user. It is not included in project synchronization or public website files. Access is restricted to that user and Windows SYSTEM. This protects the file at rest, not against malicious software already running as the same user.

Discord-derived collection records must use encrypted local storage before the collector is activated. The existing manual-import Codemoji Vault is currently unencrypted and is not automatically the bot's collection store. No bot-derived collection records are currently being saved.

Third parties and sharing

Posts in a private Discord server are stored and processed by Discord under its Privacy Policy. Private server membership does not make those posts local-only.

No Codemoji-operated cloud collection service, advertising or analytics is configured. No cross-device transfer of bot-collected data is active. Future optional media fetching would contact the relevant source service and must be disclosed and reviewed before activation.

Codemoji's existing attachment action requests a paste into an unsent Codex draft and never automatically submits it. Codex may nevertheless stage or upload an attachment before the draft is sent. Any future integration of bot-collected items with that action must be explicit; it is not currently implemented. Service processing is governed by the selected service's settings and policies.

Retention, correction and deletion

Collection records are intended to be retained only as needed for the selected personal collection. Before activation, the operator must implement and verify removal and correction controls, describe the relationship between source-message deletion and collection removal, and provide a way to request deletion of retained API data. Source-message deletion alone must not be advertised as erasing all retained copies unless that behavior is implemented and verified.

Disconnecting or stopping a bot is not the same as deleting stored records or revoking its credential. Those actions must be described separately in the final policy and controls.

For a sensitive request, ask for a private contact arrangement without including the sensitive details in the issue.
